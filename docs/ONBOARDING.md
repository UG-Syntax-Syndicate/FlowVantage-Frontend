# FlowVantage Frontend Onboarding

## 1) Project Goal
FlowVantage-Frontend is the web client for a unified project management workspace.  
The frontend should keep workflows simple, fast, and reliable for project teams.

## 2) What New Contributors Should Understand First
- Product domain: projects, contacts, calendars, emails, notes, AI-assisted organization
- User-first development: every UI change should support a clear user workflow
- Maintainability: prefer clear structure and predictable patterns over clever shortcuts

## 3) Recommended Learning Path
1. Read `README.md` for repository purpose.
2. Read `CONTRIBUTING.md` for delivery standards.
3. Read `docs/VERCEL_DEPLOYMENT.md` to understand preview/production deployment flow.
4. Read `docs/PERFORMANCE_OPTIMIZATION.md` before implementing UI-heavy features.

## 4) Contribution Expectations
- Keep changes scoped and reviewable.
- Update docs when process, architecture, or behavior changes.
- Include clear validation notes in every pull request.
- Treat performance as a feature requirement, not a later task.

## 5) Done Criteria for Frontend Work
- Feature/fix meets acceptance criteria
- No regressions in existing behavior
- Deployment configuration still supports preview + production
- Performance impact has been checked and documented where relevant
